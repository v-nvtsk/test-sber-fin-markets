# Тестовое задание 

## Задача
Дано: массив заголовков и массив значений

```js
const titles = [
    { key: 'id',  title: 'ID'},
    { key: 'name',  title: 'Имя'},
    { key: 'code',  title: 'Код'},
]

const data = [
    { id: '1', 'name': 'John Doe', code: '001' },
    { id: '2', 'name': 'Lawrence Smith', code: '001' },
    { id: '3', 'name': 'Jolene Parton', code: '001' },
]
```

**Необходимо**:

Реализовать React-компонент, который построит из этих данных таблицу (для экрана шире 768 пикселей)
или список карточек с данными (для экранов шириной до 768 пикселей включительно).  
Минимальное разрешение, на котором информация должна быть читаема -- 375 пикселей  

Желательно реализовать с применением TypeScript,  
JSS или SCSS -- на усмотрение кандидата.  
Дизайн -- на усмотрение кандидата.

## Описание решения

Приложение состоит из двух компонентов `App` и `DataView`
`App` отвечает за получение данных от сервера,
`DataView` отвечает за отображение данных.


Согласно задания для стилизации `DataView` использован **SCSS**.  
Для стилизации `App` применил **css-модули**.  
С **JSS** не сталкивался и не уверен, что это не опечатка.

Деплой приложения выполнен с помощью github actions: https://v-nvtsk-github.io/test-sber-fin-market


## Локальный запуск

Склонировать репозиторий

```

```
